# README_EXTRA_PROMPTS_ICONES_V2

Ce pack contient des **prompts additionnels mono-icône** pour enrichir la bibliothèque d’icônes du Stat Tracker de Tactical GM Suite.

## Point important

Cette V2 corrige un défaut de la version précédente :
les prompts sont maintenant **autonomes**.

Autrement dit :
- ils ne supposent plus qu’un futur ChatGPT aura accès aux images modèles ;
- la section **PRÉCISIONS SPÉCIFIQUES À CETTE ICÔNE** décrit directement le sujet à produire.

## Contenu

Le pack inclut :
- 5 nouvelles icônes demandées explicitement :
  - Lingot d’or
  - Lingot de fer
  - Lingot de cuivre
  - Rubis
  - Boîte à outils
- 10 nouvelles icônes décrites à partir des modèles fournis :
  - Corbeau
  - Masque
  - Pierres
  - Hache
  - Bourse
  - Coffre
  - Gelée
  - Boule de feu
  - Livre
  - Feuille

## Utilisation recommandée

Pour chaque icône :
1. ouvrir idéalement un nouveau chat ;
2. joindre un seul fichier prompt ;
3. écrire : `Suis ce prompt et seulement lui.`
4. laisser générer une seule image ;
5. passer ensuite au fichier suivant.
