# README_48_PROMPTS_ICONES

Ce pack contient les **48 prompts mono-icône** pour la bibliothèque V1 du Stat Tracker de Tactical GM Suite.

## Logique recommandée

Pour chaque icône :

1. ouvrir idéalement un **nouveau chat** ;
2. joindre **un seul fichier prompt** ;
3. écrire : `Suis ce prompt et seulement lui.`
4. laisser générer une seule image ;
5. passer ensuite au fichier suivant.

## Pourquoi cette méthode

Les essais précédents ont montré que les prompts de lot peuvent provoquer :
- des planches ;
- des variantes multiples du même sujet ;
- une contamination par les images ou sujets précédents.

La méthode **mono-icône** est la plus robuste :
- 1 fichier ;
- 1 sujet ;
- 1 génération ;
- 1 image finale.

## Structure

- `body/` : Corps & Protection
- `arcane/` : Arcane & Combat
- `resource/` : Ressources & Richesses
- `object/` : Objets & Marques

Un fichier `INDEX_48_PROMPTS_ICONES.md` récapitule toute la bibliothèque.
