# PROMPT_ICONE_RESOURCE_TORCH_FR

## Tactical GM Suite — Génération d’une icône Stats

### IMPORTANT

Ce fichier sert à générer **une seule icône**.

Sujet autorisé unique :

**Torche**

ID technique :

`resource_torch`

Catégorie :

`resource`

Utiliser le générateur d’images pour créer exactement **UNE image finale** représentant uniquement :

**Torche**

Ne générer qu’une seule sortie.
Ne créer aucune variante.
Ne créer aucune planche.
Ne créer aucune grille.
Ne créer aucun sprite sheet.
Ne réutiliser aucune image précédente comme base ou référence.

Il s’agit d’une **nouvelle génération indépendante à partir du texte uniquement**.

# PRÉCISIONS SPÉCIFIQUES À CETTE ICÔNE

- torche simple avec manche et flamme lisibles
- pas de personnage la tenant
- aspect utilitaire fantasy

Palette / ambiance dominante :

- bois brun, flamme orange chaude

# DIRECTION ARTISTIQUE COMMUNE

Créer un asset d’icône fantasy stylisée originale pour une interface de jeu de rôle tactique.

Style général :

- icône d’inventaire RPG fantasy moderne ;
- stylisée ;
- légèrement semi-réaliste ;
- rendu peint propre ;
- simple et compacte ;
- silhouette immédiatement reconnaissable ;
- volume doux ;
- contour sombre propre et discret ;
- reflets modérés ;
- ombres légères ;
- couleurs riches mais non flashy ;
- matière facilement identifiable ;
- lumière douce venant du haut-gauche.

L’icône doit être visuellement soignée mais rester simple.

Elle sera affichée à environ 24 à 32 px, donc la lisibilité prime.

Privilégier :

- une forme principale claire ;
- quelques grandes zones de volume ;
- peu de détails ;
- peu d’ornements ;
- contraste net ;
- lecture immédiate.

# COMPOSITION

L’image doit contenir :

- exactement une seule icône ;
- exactement un seul sujet ;
- aucun autre objet.

Composition :

- canvas carré ;
- sujet centré ;
- sujet occupant environ 75 à 85 % du canvas ;
- petite marge de sécurité sur les quatre côtés ;
- aucune partie coupée ;
- légère vue 3/4 si elle améliore la lecture ;
- vue frontale autorisée si elle est plus claire.

Ne pas ajouter :

- cadre ;
- disque de fond ;
- plaque ;
- personnage ;
- main ;
- décor ;
- paysage ;
- texte ;
- chiffre ;
- logo ;
- watermark ;
- barre ;
- compteur ;
- bouton ;
- élément UI.

# FOND

Le fond doit être **réellement transparent avec canal alpha**.

Interdictions :

- fond noir ;
- fond blanc ;
- fond gris ;
- fond coloré ;
- dégradé ;
- vignette ;
- damier visible ;
- faux motif de transparence ;
- décor d’arrière-plan ;
- faux sol.

# ORIGINALITÉ

Créer un asset original.

Ne pas copier ou reproduire de trop près :

- une icône provenant d’un autre addon ;
- un asset de jeu existant ;
- un pack commercial ;
- un logo ;
- un emblème protégé.

# OUTILS INTERDITS

Ne pas créer ou remplacer l’icône avec :

- Python ;
- PIL / Pillow ;
- SVG généré par code ;
- Canvas ;
- HTML/CSS ;
- scripts ;
- formes procédurales ;
- dessin programmatique.

L’asset final doit provenir du générateur d’images.

# VALIDATION

Le résultat est valide uniquement si :

- il y a exactement une seule icône ;
- cette icône représente uniquement le sujet demandé ;
- il n’y a aucune variante ;
- il n’y a aucun autre objet ;
- le fond est réellement transparent ;
- il n’y a aucun décor ni élément d’interface ;
- l’icône reste lisible à petite taille.

Si le résultat est invalide, régénérer uniquement cette même icône.

# FIN

Résultat attendu :

**exactement une image finale de cette icône, et rien d’autre.**
